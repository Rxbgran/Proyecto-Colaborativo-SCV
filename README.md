💻 **Project Contribution**

In this phase of development, several major improvements were implemented to enhance both gameplay and overall project functionality. The character controller was refined, including rotation, movement direction, and animation transitions. Additional scripts were modified and expanded to support new features such as health management, enemy damage detection, projectile attacks, and trigger-based audio interactions.

A complete enemy system was introduced, allowing enemies to receive variable amounts of damage, display different behaviors, and trigger the victory condition once all of them are defeated. The player now has a full life system, UI updates, game-over logic, and a return to the main menu when lives reach zero. Several design elements were improved, including environment adjustments, sound placement, collision fixes, and the general flow between scenes.

The game now features a functional combat loop: the player can shoot projectiles, enemies react to damage, and both defeat and victory conditions are fully operational. Menu navigation, scene transitions, and the build process were cleaned and optimized to ensure a complete, stable, and playable experience.
